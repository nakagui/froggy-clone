# Froggy 🐸

A simple game inspired by the classic **Frogger**, developed using **Unity and C#** as a personal learning project.

The goal of this project is to practice game development fundamentals, explore Unity features and improve my C# programming skills.

## 🎮 Gameplay

Control a frog and guide it safely across busy roads and dangerous rivers while avoiding moving obstacles. Reach the other side without getting hit or falling into the water.

## 🛠️ Technologies

- **Unity** – Game engine
- **C#** – Programming language

## 📚 Learning Objectives

- Practice Unity 2D physics system
- Implement player movement and input handling
- Practice collision detection and trigger interactions
- Create moving obstacles and traffic patterns
- Implement moving platforms and river mechanics
- Manage player lives and gameover conditions
- Implement scoring and level progression systems
- Manage basic game states (start, gameover, restart)
- Improve code organization and C# skills

## 🚀 Getting Started

1. Clone this repository.
2. Open **Unity Hub**.
3. Add the cloned project to Unity Hub.
4. Open the project using its compatible Unity version.
5. Open the main scene and press **Play**.
